# FinScope Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task.

**Goal:** Deliver and publish an interactive evidence-grounded financial risk research workbench with runnable Python experiments.
**Architecture:** Python validates inputs, builds as-of features, runs purged rolling experiments and writes a versioned report. Buildless HTML/CSS/JS consumes the same JSON from static artifacts or a loopback FastAPI service. Research documents describe exactly what is implemented and what is only inspiration.
**Tech Stack:** Python 3.12, numpy, pandas, scikit-learn, EdgarTools, FastAPI, uvicorn, pytest, HTML/CSS/JavaScript/SVG.
**Spec:** docs/superpowers/specs/2026-10-14-finscope-design.md

## Global Constraints
- Public brand: Leon Wang; English-first copy.
- Public prices/social/logs are explicitly synthetic, real SEC snapshots remain separately labelled.
- Never claim successful financial improvements from synthetic data.
- No paid APIs, private data publication, secret exposure, live trading or externally hosted training service.
- Price labels are 5/20-session annualized realized volatility; all event features obey max(available_at, ingested_at).
- All figures must be computed, no hardcoded performance claims.
- Use .venv/bin/python in this repository; dependencies installed by coordinator.
